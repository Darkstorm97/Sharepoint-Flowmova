# Journal des décisions

Ce répertoire conserve les décisions importantes relatives au produit et à l'architecture.

Chaque décision utilisera un fichier numéroté :

```text
0001-titre-de-la-decision.md
```

Une décision doit préciser :

- son statut : proposée, acceptée, remplacée ou abandonnée ;
- le contexte et le problème ;
- les options considérées ;
- la décision retenue ;
- ses conséquences positives et négatives.

Les décisions déjà établies dans le cadre global seront transformées en fiches distinctes lorsqu'elles nécessiteront une justification ou auront un effet durable sur l'architecture.
