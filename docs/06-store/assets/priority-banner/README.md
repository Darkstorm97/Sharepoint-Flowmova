## Captures et légendes

### 1. Niveaux de priorité

- fichier : `01-priority-levels.png`
- FR : Adaptez chaque communication à son niveau de priorité, d’Important à Critique.
- EN : Match every communication to the right priority level, from Important to Critical.

### 2. Formats Standard et Compact

- fichier : `02-standard-and-compact.png`
- FR : Choisissez un affichage détaillé ou compact, avec un bouton d’action facultatif.
- EN : Choose a detailed or compact layout with an optional action button.

### 3. Configuration bilingue

- fichier : `03-bilingual-configuration.png`
- FR : Ajoutez une traduction française facultative; la langue SharePoint du visiteur détermine automatiquement le contenu affiché.
- EN : Add an optional French translation; the visitor’s SharePoint language automatically determines the displayed content.

### 4. Configuration simple

- fichier : `04-simple-configuration.png`
- FR : Configurez le titre, le message, la priorité et l’expiration directement dans les propriétés de la page.
- EN : Configure the title, message, priority, and expiration directly in the page properties.

### 5. Aperçu mobile

- fichier : `05-mobile-preview.png`
- FR : Conservez des communications claires et lisibles sur les appareils mobiles.
- EN : Keep priority communications clear and readable on mobile devices.
