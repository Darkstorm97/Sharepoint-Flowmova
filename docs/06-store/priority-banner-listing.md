## Description française

### Rendez les communications importantes immédiatement visibles

Priority Banner permet d’ajouter rapidement un message prioritaire à une page SharePoint moderne. Il convient aux annonces importantes, interruptions de service, rappels, alertes opérationnelles et communications internes.

Chaque bandeau est configuré directement dans la page, sans liste SharePoint, service externe ou infrastructure Azure. Plusieurs messages indépendants peuvent être ajoutés à une même page.

Fonctionnalités principales :

- quatre niveaux : Information, Important, Urgent et Critique ;
- formats Standard et Compact ;
- titre obligatoire et message facultatif ;
- bouton d’action et expiration facultatifs ;
- fermeture persistante dans le navigateur ;
- messages Critiques non fermables ;
- français et anglais sélectionnés selon la langue SharePoint ;
- thèmes SharePoint et appareils mobiles pris en charge ;
- aucune permission Microsoft Graph ni transmission vers un service externe.

## English description

### Make important communications immediately visible

Priority Banner lets organizations add a clear priority message to any modern SharePoint page. It is suitable for important announcements, service interruptions, reminders, operational alerts, and internal communications.

Each banner is configured directly on the page without requiring a SharePoint list, external service, or Azure infrastructure. Multiple independent messages can be added to the same page.

Key features:

- four priority levels: Information, Important, Urgent, and Critical;
- Standard and Compact layouts;
- required title and optional message;
- optional action button and expiration;
- persistent browser-based dismissal;
- non-dismissible Critical messages;
- French and English selected according to the SharePoint language;
- SharePoint theme and mobile support;
- no Microsoft Graph permissions or external data transmission.
